# v0.8.0 (dev)

## Upgrading

- The `pid_attributes` section of the wallet configuration has a new format. The
  path to an mdoc attribute is now an object with `namespace` and `element_name`
  instead of an array, and the path to an SD-JWT attribute is the name of a
  top-level claim instead of an array. The claim names `_sd` and `...` are
  rejected, as SD-JWT reserves them. For example:

    ```json
    "pid_attributes": {
      "mso_mdoc": {
        "eu.europa.ec.eudi.pid.1": {
          "login": { "namespace": "eu.europa.ec.eudi.pid.nl.1", "element_name": "bsn" },
          "recovery_code": { "namespace": "eu.europa.ec.eudi.pid.nl.1", "element_name": "recovery_code" }
        }
      },
      "sd_jwt": {
        "urn:eudi:pid:nl:1": { "login": "bsn", "recovery_code": "recovery_code" }
      }
    }
    ```
