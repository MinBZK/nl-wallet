# Use Case 5.1 Share data with a Relying Party

## Overview

| Aspect                       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Summary**                  | The user shares personal data with a Relying Party by initiating the process on the Relying Party site, confirming their identity in the NL Wallet app,<br>reviewing organization and data details, and then confirming the disclosure with PIN.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Goal**                     | Share data with a Relying Party.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Preconditions**            | <ul><li>The App holds the requested data.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Postconditions**           | <ul><li>Data is shared with Relying Party.</li><li>The disclosure event is added in the history.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| **Triggered by**             | <ul><li>User invokes a universal link that contains the URL to a Relying Party.</li><li>User scans QR with in-app scanner [UC9.9 Scan QR](UC9.9_ScanQR.md)</li><li>Verifier scans QR [UC5.3 Show QR](UC5.3_ShowQR.md)</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Additional Documentation** | <ul><li>[Disclosure with openidp4vp](../../architecture/use-cases/disclosure-with-openid4vp.md)</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Possible errors**          | <ul><li>[No Internet](../errors.md#no-internet)</li><li>[Server Unreachable](../errors.md#server-unreachable)</li><li>[Session Expired](../errors.md#session-expired)</li><li>[Known Verifier Error](../errors.md#known-verifier-error)</li><li>[Unknown Verifier Error](../errors.md#unknown-verifier-error)</li><li>[Bluetooth Disconnected Error](../errors.md#bluetooth-disconnected-error)</li></ul>                                                                                                                                                                                                                                                                                                                                  |
| **Logical test cases**       | <ul><li>[LTC15 Share data](../logical-test-cases.md#ltc15)</li><li>[LTC16 Cross-device share data](../logical-test-cases.md#ltc16)</li><li>[LTC17 Decline consent to share data](../logical-test-cases.md#ltc17)</li><li>[LTC10 Wallet does not contain requested attributes](../logical-test-cases.md#ltc10)</li><li>[LTC26 Disclosure fails](../logical-test-cases.md#ltc26)</li><li>[LTC65 Select another card to be disclosed ](../logical-test-cases.md#ltc65)</li><li>[LTC79 Close proximity data sharing](../logical-test-cases.md#ltc79)</li><li>[LTC80 Missing attributes at close proximity](../logical-test-cases.md#ltc80)</li><li>[LTC81 Reader disconnects during close proximity](../logical-test-cases.md#ltc81)</li></ul> |
