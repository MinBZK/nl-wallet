# Use Case 9.11 Configure Notifications

## Overview

| Aspect                       | Description                                                                                                                                                                                                                                                           |
|------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Summary**                  | The user turns push notifications on or off. When the app does not have permission to send notifications yet, the operating system asks for it. When notifications are blocked in the device settings, the app shows an alert that points the user to those settings. |
| **Goal**                     | Managing whether the user receives alerts about card changes, app updates and other important messages.                                                                                                                                                               |
| **Preconditions**            | *None*                                                                                                                                                                                                                                                                |
| **Postconditions**           | <ul><li>Push notifications are enabled or disabled.</li><li>The app setting matches the notification permission granted at operating system level.</li></ul>                                                                                                          |
| **Triggered by**             | <ul><li>User selects 'Notifications' in [UC9.1 Show app menu](UC9.1_ShowAppMenu.md).</li></ul>                                                                                                                                                                        |
| **Additional Documentation** | <ul><li>[Notifications](../notifications.md)</li></ul>                                                                                                                                                                                                                |
| **Possible errors**          | *None*                                                                                                                                                                                                                                                                |
| **Logical test cases**       | <ul><li>[LTC71 Card status update notifications](../logical-test-cases.md#ltc71)</li><li>[LTC72 Configure notifications](../logical-test-cases.md#ltc72)</li></ul>                                                                                                    |

---

## Flow

| #       | Description                                                                                                                                                                                                                                                         | Next |
|---------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------|
| **1**   | **PRIMARY SCENARIO**                                                                                                                                                                                                                                                |      |
| **1.1** | **System displays screen 'Notifications'**<ul><li>Message: Get alerts about your cards changes, app updates, and other important messages.</li><li>Toggle: Push notifications &mdash; Get alerts, even when you don’t open the app.</li><li>Actions: Back</li></ul> |      |
| 1.1a    | User toggles push notifications on                                                                                                                                                                                                                                  | 1.2  |
| 1.1b    | User toggles push notifications off <br>&rarr; Push notifications are disabled                                                                                                                                                                                      |      |
| 1.1c    | User selects Back                                                                                                                                                                                                                                                   | Back |
| **1.2** | **System determines whether permission to send notifications was granted**<sup>1</sup>                                                                                                                                                                              |      |
| 1.2a    | Case: Permission is granted <br>&rarr; Push notifications are enabled                                                                                                                                                                                               | 1.1  |
| 1.2b    | Case: Permission was not requested before                                                                                                                                                                                                                           | 1.3  |
| 1.2c    | Case: Permission is permanently denied                                                                                                                                                                                                                              | 2    |
| **1.3** | **Operating system asks permission to send notifications**<ul><li>iOS: “NL Wallet” Would Like to Send You Push Notifications</li><li>Android: Allow NL Wallet to send you notifications?</li><li>Actions: Allow, Don’t allow</li></ul>                              |      |
| 1.3a    | User selects Allow <br>&rarr; Push notifications are enabled                                                                                                                                                                                                        | 1.1  |
| 1.3b    | User selects Don’t allow <br>&rarr; Push notifications stay disabled                                                                                                                                                                                                | 1.1  |
| **2**   | **WHEN NOTIFICATIONS ARE BLOCKED IN THE DEVICE SETTINGS**                                                                                                                                                                                                           |      |
| **2.1** | **System displays alert 'Change push notifications?'**<ul><li>Message: To change this, go to your phone settings.</li><li>Actions: CLOSE, OPEN SETTINGS</li></ul>                                                                                                   |      |
| 2.1a    | User selects CLOSE                                                                                                                                                                                                                                                  | 1.1  |
| 2.1b    | User selects OPEN SETTINGS                                                                                                                                                                                                                                          | 2.2  |
| **2.2** | **System opens the notification settings of the device and suspends the app**                                                                                                                                                                                       |      |
| 2.2a    | User enables notifications and returns to the app <br>&rarr; Push notifications are enabled                                                                                                                                                                         | 1.1  |
| 2.2b    | User returns to the app without enabling notifications                                                                                                                                                                                                              | 1.1  |

<div class="table-notes">1. The operating system is only asked for permission when the user actively turns the toggle on.</div>
