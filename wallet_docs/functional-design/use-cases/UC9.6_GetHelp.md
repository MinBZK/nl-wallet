# Use Case 9.6 Get help

## Overview

| Aspect                       | Description                                                                                                                                                                                                          |
|------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Summary**                  | The user browses the in-app help to find an answer to a question, by drilling down from a category to a subcategory to a topic, or contacts the help desk.                                                           |
| **Goal**                     | Finding an answer to a question about using the app.                                                                                                                                                                 |
| **Preconditions**            | *None*                                                                                                                                                                                                               |
| **Postconditions**           | *None*                                                                                                                                                                                                               |
| **Triggered by**             | <ul><li>User selects 'Help and information' in [UC9.1 Show app menu](UC9.1_ShowAppMenu.md)</li><li>User selects 'Help and information' in [UC7.1 App overview](UC7.1_AppOverview.md)</li></ul>                       |
| **Additional documentation** | *None*                                                                                                                                                                                                               |
| **Possible errors**          | <ul><li>[Generic Error](../errors.md#generic-error)</li></ul>                                                                                                                                                        |
| **Logical test cases**       | <ul><li>[LTC31 Get help](../logical-test-cases.md#ltc31)</li></ul>                                                                                                                                                   |

---

## Flow

| #       | Description                                                                                                                                                                                                       | Next                                                    |
|---------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------|
| **1**   | **PRIMARY SCENARIO**                                                                                                                                                                                              |                                                         |
| **1.1** | **System loads the help content and displays loading indicator**                                                                                                                                                  |                                                         |
| 1.1a    | Case: Help content is loaded                                                                                                                                                                                      | 1.2                                                     |
| 1.1b    | Error: Help content cannot be loaded                                                                                                                                                                              | Error flow: [Generic Error](../errors.md#generic-error) |
| **1.2** | **System displays screen 'Help and information'**<ul><li>Items: See how NL Wallet works, [Help category] (one per category), Contact</li><li>Actions: Back</li></ul>                                              |                                                         |
| 1.2a    | User selects See how NL Wallet works                                                                                                                                                                              | Go to: [UC1.3 App tour](UC1.3_AppTour.md)               |
| 1.2b    | User selects a help category                                                                                                                                                                                      | 1.3                                                     |
| 1.2c    | User selects Contact                                                                                                                                                                                              | 2                                                       |
| 1.2d    | User selects Back                                                                                                                                                                                                 | Back                                                    |
| **1.3** | **System displays screen '[Help category]'**<ul><li>Items: [Subcategory] (one per subcategory of the selected category)</li><li>Actions: Back</li></ul>                                                           |                                                         |
| 1.3a    | User selects a subcategory                                                                                                                                                                                        | 1.4                                                     |
| 1.3b    | User selects Back                                                                                                                                                                                                 | Back                                                    |
| **1.4** | **System displays screen '[Subcategory]'**<ul><li>Items: [Topic] (one per topic of the selected subcategory)</li><li>Actions: Back</li></ul>                                                                      |                                                         |
| 1.4a    | User selects a topic                                                                                                                                                                                              | 1.5                                                     |
| 1.4b    | User selects Back                                                                                                                                                                                                 | Back                                                    |
| **1.5** | **System loads the topic and displays loading indicator**                                                                                                                                                         |                                                         |
| 1.5a    | Case: Topic is loaded                                                                                                                                                                                             | 1.6                                                     |
| 1.5b    | Error: Topic cannot be loaded                                                                                                                                                                                     | Error flow: [Generic Error](../errors.md#generic-error) |
| **1.6** | **System displays screen '[Topic]'**<ul><li>Topic content</li><li>'Other questions': links to related topics<sup>1</sup></li><li>Actions: [Related topic], Something else?, Back</li></ul>                        |                                                         |
| 1.6a    | User selects a related topic                                                                                                                                                                                      | 1.5                                                     |
| 1.6b    | User selects Something else?                                                                                                                                                                                      | 2                                                       |
| 1.6c    | User selects Back                                                                                                                                                                                                 | Back                                                    |
| **2**   | **CONTACT**                                                                                                                                                                                                       |                                                         |
| **2.1** | **System displays screen 'Contact'**<ul><li>Message: Want to know more about the NL Wallet? Check our website or contact us.</li><li>Call us: availability and phone number</li><li>Actions: Call, Back</li></ul> |                                                         |
| 2.1a    | User selects Call                                                                                                                                                                                                 | Show placeholder 'under construction'                   |
| 2.1b    | User selects Back                                                                                                                                                                                                 | Back                                                    |

<div class="table-notes">1. Topics that are already on the path that led to the current topic are left out of 'Other questions'.</div>
